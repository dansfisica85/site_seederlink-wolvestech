1 INTRODUÇÃO 
1.1 Por que o CSS às vezes não funciona nos componentes? 
Se você está praticando bastante, provavelmente já se deparou com algumas 
situações estranhas na hora de estilizar os componentes usando o CSS, ainda mais 
quando usamos os nomes das tags como seletor. Isso ocorre porque, ao ser 
renderizado na página HTML, o CSS não fica separado por componente. 
Vamos criar uma situação simples e comum para percebemos melhor o 
problema. Criaremos um projeto do react utilizando o template do Vite, chamado 
exemplo-estilizacao. Não se esqueça de remover os arquivos desnecessários para 
nosso projeto, queremos apenas o componente App com um título (H1), “Exemplo 
Estilização”.

A primeira solução que vem a nossa cabeça para resolver este problema seria: 
“Vamos atribuir id’s e classes a todos os elementos, assim não vamos ter mais este 
tipo de problema”. Realmente, isso faz todo o sentido, mas, se nossa aplicação for 
muito grande, vai ser difícil de gerenciar tantas informações e erros vão acontecer... 
Para solucionar este tipo de problema, foi criada uma biblioteca chamada 
styled-components, ela irá gerenciar este tipo de problema para nós. 
A primeira coisa de devemos fazer para utilizá-la é fazer a instalação do pacote. 
Vá até o terminal e pare a aplicação com “Ctrl + C” e, após fazer isso, insira a linha de 
código abaixo e depois tecle ENTER:  
npm install –save styled-components 
Pode ser que demore um pouco, mas geralmente é bem rápido. Assim que 
terminar a instalação e aparecer o prompt novamente, é só usar o npm run dev para 
subirmos nossa aplicação novamente. Pronto, agora é só começar a usar. 
1.1.1 Usando o styled-components de forma externa 
Podemos utilizar o styled-components de várias formas. A primeira que vamos 
ver é criando um arquivo externo para estilizar os componentes, isso pode ser 
bastante útil, pois sendo externo, podemos reaproveitar o código em outros 
componentes. 
Dentro da pasta src crie um arquivo chamado styled.js, como ele é uma 
biblioteca feita em JavaScript, sua extensão também será js. Vamos de início apenas 
inserir um fundo a nossa div que está dentro do Componente1. Para isso, reproduza 
o código abaixo dentro do styled.js: 
 
 
 
import styled from 'styled-components' 
 
export const DivComp1 = styled.div` 
    background-color: #ddf; 
`

O código parece confuso, não é? Calma, vamos ver cada parte e entender o

Na primeira linha, estamos importando a biblioteca, demos o nome de styled

como se fosse em um arquivo CSS tradicional, usando “;” e tudo mais. 
Ah! Não se esqueça de colocar a palavra reservada “export” antes da constante

1.1.3 USANDO O STYLED-COMPONENTS DE FORMA GLOBAL 
Com certeza você já deve ter feito configurações iniciais em seu projeto para 
definir algumas estilizações que seriam aplicadas em todos os elementos da página. 
Nós costumamos chamar de reset, pois limpamos configurações que são padrão do 
navegador e não serão úteis para nós e ajustamos nossas preferencias, para, assim, 
personalizar as páginas conforme o estilo de nosso projeto. 
Até então criamos estilizações para serem atribuídas para elementos 
específicos e seus filhos, por isso, criamos constantes contendo as estilizações e 
depois atribuímos ao elemento, substituindo o nome da tag pelo nome de nossa 
constante. Mas agora vamos criar um arquivo chamado estiloGlobal.js, nele vamos 
criar nossas configurações padrão que serão replicadas em toda a página. Crie o 
arquivo na pasta src e faça conforme abaixo: 
 
 
import { createGlobalStyle } from "styled-components"; 
 
const globalStyle = createGlobalStyle` 
    *{ 
        margin: 0; 
        padding: 0; 
        box-sizing: border-box; 
        font-family: Arial, Helvetica, sans-serif; 
    } 
 
` 
export default globalStyle

1.4 Usando o fetch para consumir dados de uma API 
Nosso formulário evoluiu bastante, não é? Mas ainda podemos fazer mais um 
upgrade nele, vamos agora consumir dados externos, disponibilizados por uma API. 
Uma API é uma aplicação que permite a troca de informações, ou 
simplesmente o consumo delas. No nosso caso, vamos consumir informações de uma 
API gratuita que disponibiliza dados de logradouros (endereços) ao informarmos 
apenas o CEP deste endereço. Tenho certeza de que você já preencheu um 
formulário na web em que, ao digitar o seu CEP, ele automaticamente preencheu a 
maioria dos dados do endereço, deixando apenas o número da casa, complemento e 
outras informações que não conseguimos a partir de um CEP, não é? 
Mas, como buscar dados em outros endereços da web? No JavaScript, temos 
um método chamado fetch, o qual nos permite realizar ações de troca de dados na 
internet. Tal qual quando estamos na internet, podemos por vários motivos não 
conseguir a informação desejada. O fetch trabalha com um sistema chamado de 
promisses (promessas), é um sistema assíncrono que faz uma solicitação e, se ela 
receber a resposta esperada, ele nos devolve, senão apresenta uma mensagem de 
erro. Uma outra característica que faz ele usar este sistema é que, como estamos 
trabalhando na internet, pode ser que a resposta demore um pouco e, por isso, ele é 
assíncrono, para a sua aplicação não travar esperando a resposta. 
Vamos aumentar nosso formulário com informações de endereço, assim vamos 
conseguir utilizar os dados da API. Faça as alterações destacadas no código abaixo:
