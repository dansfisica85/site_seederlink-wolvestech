1 INTRODUÇÃO 
1.1 JQuery Introdução 
O objetivo do jQuery é facilitar o uso do JavaScript em seu site. 
Antes de começar a praticar o jQuery, você deve ter um conhecimento mínimo 
em HTML, CSS e JavaScript. 
1.1.1 O que é o JQuery 
jQuery é uma biblioteca JavaScript leve, "escreva menos, faça mais". O objetivo 
do jQuery é facilitar o uso do JavaScript em seu site ao pegar muitas tarefas comuns 
que requerem muitas linhas de código JavaScript para serem realizadas, agrupando-
as em métodos, os quais você pode chamar com uma única linha de código. 
jQuery também simplifica muitas das coisas mais complexas do JavaScript, 
como chamadas AJAX e manipulação de DOM. 
A biblioteca jQuery contém os seguintes recursos: 
 Manipulação de HTML/DOM. 
 Manipulação de CSS. 
 Métodos de evento HTML. 
 Efeitos e animações. 
 AJAX.

2.2 Document Ready 
Uma observação importante para os códigos exemplos que iremos utilizar, 
todos os métodos jQuery que utilizaremos estão dentro de um $(document).ready. 
Isso evita que qualquer código jQuery seja executado antes que o documento termine 
de carregar. 
É uma boa prática esperar que o documento esteja totalmente carregado e 
pronto antes de trabalhar com ele. Isso também permite que você tenha seu código 
JavaScript antes do corpo do seu documento, na seção head. 
Veja alguns exemplos de ações que podem causar uma falha se os métodos 
forem executados antes de o documento ser totalmente pronto para uso: 
 Tentando esconder um elemento que ainda não foi criado. 
 Tentando obter o tamanho de uma imagem que ainda não foi carregada. 
Veja as duas formas de utilizarmos a função: 
 
$(document).ready(function(){ 
  // Código 
});

4 JQUERY – MANIPULANDO CONTEÚDO E ATRIBUTOS 
4.1 jQuery DOM 
Uma das funcionalidades interessantes do jQuery é a possibilidade de 
manipular o DOM (Document Object Model). O jQuery vem com vários métodos 
relacionados ao DOM que possibilitam o acesso e a manipulação de elementos e 
atributos. Por meio do DOM, é possível que programas ou scripts tenham acesso 
dinamicamente a conteúdos, estruturas e estilos. 
4.1.1 Obtendo conteúdo - text(), html() e val() 
Três métodos jQuery simples, mas úteis, para manipulação de DOM são: 
 text()- Define ou retorna o conteúdo de texto dos elementos selecionados. 
 html()- Define ou retorna o conteúdo dos elementos selecionados (incluindo 
marcação HTML). 
 val()- Define ou retorna o valor dos campos do formulário.
